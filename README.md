## Инструкция
1. Перенести префаб Shakaler на сцену
2. Прикрепить префаб(Лучше целиком) к камере, на которую должен выводиться объект
3. Удалить из этой камеры из пункта culling слой ShakalEffect(создаётся автоматически)

4. Все объекты, лежащие в слое ShakalEffect будут зашакалены

## Если слой не создался
Project Settings → Tags and Layers → добавить слой с именем ShakalEffect
в любую свободную ячейку
